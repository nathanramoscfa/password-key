How it’s random

The browser’s CSPRNG, nothing less.

Every draw comes from crypto.getRandomValues — the same operating-system entropy source the Python package reaches through secrets. Selection uses rejection sampling, so no character or word is ever more likely than another. Math.random() appears nowhere on this page.

The math

Entropy, counted honestly.

A 32-character URL-safe password carries about 193 bits — far beyond any brute-force attack. A six-word passphrase from the EFF Large Wordlist carries log₂(7776) ≈ 12.9 bits per word: 77.5 bits at six words, enough to resist offline cracking on serious hardware, and far easier to type on a phone or read over a call.

When require every class is on, the meter reports log₂ of the accepted-string count by inclusion–exclusion, not the naive figure. Composition rules make short passwords slightly weaker, and the gauge says so.

Local by construction

Verifiable, not promised.

The page ships a Content-Security-Policy that forbids every network request — no fetch, no beacons, no third-party scripts, ever. The wordlist is embedded, so the whole thing works offline: save the page, turn your network off, and it still rolls. The same generator is a zero-dependency Python package:

pip install password-key
pwk              # 32-char URL-safe password → clipboard
pwk --words 7    # 7-word EFF passphrase
